# Samis Flag Football

Web-App mit allen Spielen und Statistiken von Samuel Neubauer (#15) bei den Münchendorf Badgers (U13 und U15), Saisonen 2026 und 2027.

Datenquelle: AFBÖ auf [clubee.com/afbo](https://www.clubee.com/afbo).

Läuft als statische Seite auf GitHub Pages. Auf dem Handy über „Zum Home-Bildschirm“ hinzufügen, dann startet sie im Vollbild wie eine App.
